# 2048

A classic 2048 puzzle game built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

## Features

- 4x4 grid with smooth CSS animations
- Keyboard arrow key controls
- Touch/swipe support for mobile devices
- Score tracking
- Win detection (reach 2048) and game over detection
- Responsive design (desktop + mobile)
- New Game button to restart anytime

## How to Play

1. Open `index.html` in your browser
2. Use **arrow keys** (desktop) or **swipe** (mobile) to move tiles
3. Tiles with the same number merge when they collide
4. Each merge adds to your score
5. Reach **2048** to win!

## Tech Stack

| Technology | Purpose |
